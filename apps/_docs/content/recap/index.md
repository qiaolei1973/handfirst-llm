# 复习：当我们在谈机器学习时，我们在谈些什么

> 把 v1 到 v4 学过的所有概念，用一条线串起来。不按版本，按"是什么"和"为什么"。

---

机器学习，说到底，就是让计算机反复做一件事：

```
准备数据 → 训练（反复转圈）→ 评估
```

- **准备数据**：训练前做一次——切分 + 标准化
- **训练**：一个循环，每圈五步——采样 → 前向 → 损失 → 反向 → 更新
- **评估**：旁路监控——用没见过的数据考它，考不好就停

所有概念——不管听起来多复杂——都是这三块里某一块的细节。

## 一、数据处理：训练前，做一次

数据不会直接进模型。训练开始前，要先做两件事。

### 切分：留一份「没见过的」做体检

```
全部 60 个点 → 训练集 48 个（80%） + 验证集 12 个（20%）
```

- **训练集**：用来算梯度、更新参数——模型看得到。
- **验证集**：不参与训练——模型看不到，只用来检验。

为什么非要留一份？因为「模型在训练数据上做得好」说明不了什么——它可能只是把训练数据背下来了。留一份它没见过的，才能在后面（第三块）考出它的真实水平。

### 标准化（Z-score）：统一位置 + 尺度

模型有多个参数时，输入尺度不一致会让梯度的「力度」天生不均——有的参数被推得很猛，有的几乎不动，收敛参差不齐。

**标准化**把输入统一到 mean = 0、std = 1：

```
z = (x − μ) / σ
```

这一行其实包含两步：

- **减均值（中心化）** `x − μ`：让数据以 0 为对称轴——梯度推力不再「所有人同号」，自己就平衡了。
- **除标准差** `/ σ`：统一尺度——所有参数的梯度在同一个量级上竞争。

> **总称 normalize（规范化/归一化）**。Z-score 标准化是其中一种（`(x−μ)/σ` → mean 0 std 1），还有 min-max 归一化（缩到 [0,1]）。v1-v4 用的就是 Z-score。记住这个总称，后面遇到别的归一化方式就懂了。

## 二、训练：一个循环，每圈五步

训练 = 反复转一个圈。每转一圈叫一个 **epoch**，圈里五步：

```
采样 → 前向 → 损失 → 反向 → 更新
```

### 第 1 步：采样 —— 抽一个 mini-batch

不必一次看全部数据。随机抽一小撮（batch），只在这些点上算梯度、更新。下一圈再抽不同的一小撮。

**采样**（随机抽一部分数据）和**更新**（改参数）是两件独立的事。随机采样 + 梯度下降 = **SGD（随机梯度下降）**。

随机性带来探索能力——每次看到的子集不一样，不会总是走同一条路。代价是 loss 曲线在抖。**抖是探索，不是 bug。**

### 第 2 步：前向 —— 模型算预测

数据从输入一路流到输出，得出预测值。这一步的组成是**模型**。

**模型**就是「猜答案的公式」，**参数**是公式里可以调的数。最底层运算只有一个：

```
y = W·x + b
```

输入 x，乘**权重（Weight）**，加**偏置（Bias）**。这个操作叫**线性变换（Linear）**，它做三件事：缩放、旋转、平移。Linear 是砖，所有神经网络都是这块砖垒起来的。

**为什么需要激活函数**：两块 Linear 叠一起还是直线——`W₂(W₁x + b₁) + b₂` 合并后仍是一条直线。必须在线性变换之间插入**非线性**：

```
ReLU(z) = max(0, z)      z>0 时直通，z≤0 时截断
```

ReLU 给了模型「弯折」的能力。没有它，一万层网络也只能画直线。

**神经元**：把 Linear 和激活函数捆在一起 = 一个**神经元（Neuron）**。名字来自生物神经元的隐喻——树突接收信号，超过阈值才发放脉冲。一个人工神经元 = 一段折线，换不同的 W、b 控制折的位置和方向。

**隐藏层**：N 个神经元并排，接收同一个输入 x，各自输出。这一层叫**隐藏层（Hidden Layer）**——它的输入输出都在模型内部，外界看不见。

**输出层**：隐藏层后接一层**不带激活的 Linear**，把 N 个数加权求和，得到最终预测。

```
输入 x → 隐藏层 (N 个神经元, ReLU) → 输出层 (Linear) → 预测 ŷ
```

这个结构叫**多层感知机（MLP，Multilayer Perceptron）**。

![神经网络架构：一个神经元 = Linear + ReLU，隐藏层 = N 个神经元，完整结构 1 → N → 1](/recap/neural-network-architecture.svg)

**Layer 抽象**：无论隐藏层还是输出层，结构都一样——`Wx + b →（可选激活）→ 输出`，唯一区别是激活函数。抽成一个类：

```
Layer.forward(x)   → 输出        // 前向：数据流过
Layer.backward(g)  → 传给下游的梯度  // 反向：梯度流回
```

网络 = 几个 Layer 串起来。这是整个 v1–v4 里最重要的抽象。

### 第 3 步：损失 —— 算「有多差」

模型猜了一个答案。怎么知道猜得好不好？需要一个数字——**损失（Loss）**。

**MAE**（平均绝对误差）：`L = (1/n)·Σ|ŷ − y|`。差多少就是多少，V 形。

**MSE**（均方误差）：`L = (1/n)·Σ(ŷ − y)²`。平方后，差得远的点被罚得更重，曲线光滑。

关键区别不在损失本身，而在**梯度**：

- MAE 求导只剩 `sign(diff)`——差 100 和差 0.01，推动力一样
- MSE 求导留着 `2·diff`——差得越远梯度越大，越近自己减速

MSE 是默认选择。

![MAE 的损失：L = |diff|，V 形（MSE 则是光滑的抛物线）](/v1/mae-loss.png)

### 第 4 步：反向 —— 算梯度

知道「有多差」后，要算**把每个参数往哪个方向调，能让损失变小**。

**梯度**：想象蒙着眼站在山上，目标是走到谷底。你看不见整座山，但能用脚感受脚下的坡度——**往哪边斜、斜多陡**。这个「脚下的坡度」就是梯度，对每个参数分别算：`∂L/∂W`、`∂L/∂b`。它告诉你两件事：

- **方向**：正梯度 → 参数减小；负梯度 → 参数增大
- **陡峭程度**：陡 → 迈大步；缓 → 迈小步

**链式法则**：单层模型能直接求导，但多层模型里，隐藏层的参数和损失中间隔着 ReLU 和输出层，不能直接求导。答案是链式法则：

```
∂L/∂w_i = ∂L/∂yPred · ∂yPred/∂h_i · ∂h_i/∂w_i
```

梯度从输出端开始，沿网络**反方向**一层一层传回去。

**反向传播**：不是新数学，就是链式法则按层组织起来。每穿过一层做三件小事：

```
backward(上游梯度):
  ① 收：接收上游传来的 ∂L/∂output
  ② 算：用链式法则算出自己参数 (W,b) 的梯度，累加
  ③ 传：算出传给下游的 ∂L/∂input，return 出去
```

「收 → 算 → 传」，每一层都做这三件事。

![神经网络 1 → N → 1：前向（x → ŷ）与反向（梯度从 Loss 流回参数），标注反向传播的三小步](/recap/neural-network.svg)

**ReLU 的导数与死神经元**：穿过 ReLU 时 `z>0` → 导数 1（直通），`z≤0` → 导数 0（截断）。一旦某个神经元对所有输入都输出 0，它的梯度永远是 0，参数不再更新——这就是**死神经元（Dead Neuron）**，ReLU 的代价。

### 第 5 步：更新 —— 优化器改参数

梯度告诉你「往哪走」。**优化器**决定「怎么迈这一步」。

**最朴素的走法**：

```
W = W − lr · ∂L/∂W
```

**学习率（lr）**控制步长。lr 太小 → 太慢；lr 太大 → 跨过谷底来回震荡。这就是**梯度下降（Gradient Descent）**。

朴素梯度下降有三个问题：**没记忆**（每步只看当前 batch 的梯度）、**一刀切 lr**（所有参数同一个 lr）、**只靠 lr**（没有自动调节）。优化器的演进就是逐一解决：

- **Momentum（惯性）**：维护梯度指数移动平均 `v = 0.9·v + 0.1·grad`，用 `W −= lr·v` 更新。像球滚下山，方向一致时加速，反复横跳时抵消。
- **RMSProp（逐参数缩放）**：维护梯度平方平均 `s = 0.999·s + 0.001·grad²`，用 `W −= lr·grad/√(s+ε)` 更新。陡的参数自动减速，缓的参数自动加速。
- **Adam（集大成）**：Momentum + RMSProp + 偏差修正。`m̂/√(v̂)` 把步长归一化到 ~[-1,1]，再乘 lr。默认首选。

```
m = 0.9·m + 0.1·grad          v = 0.999·v + 0.001·grad²
m̂ = m/(1−0.9ᵗ)               v̂ = v/(1−0.999ᵗ)
W = W − lr · m̂/√(v̂+ε)
```

![SGD → Momentum → Adam Loss 下降对比](/v4/optimizer-comparison.png)

**学习率调度（余弦退火）**：上面所有优化器都用固定的 lr。但 lr 不必固定——**前期大、后期小**（前期快降、后期防震荡）。余弦退火让 lr 沿余弦从 `lr0` 平滑降到 0。**优化器管「怎么用梯度」，调度器管「lr 现在该多少」**——两者正交。

![余弦退火：lr 从 lr0 平滑降到 0](/v4/cosine-annealing.png)

## 三、评估：旁路监控

训练循环只管「把参数往好的方向改」。但「改得好不好」——训练循环自己回答不了，需要一个站在外面的**裁判**：评估。

### 两份损失，两个问题

- **训练损失（trainLoss）**：在训练集上算——「对这些数据拟合得怎么样？」
- **验证损失（valLoss）**：在验证集（模型没见过）上算——「真的学到了规律吗？」

注意：**只有 trainLoss 参与训练**（算梯度、更新参数）。valLoss 只 forward、不 backward、不更新——它是纯旁观的读数，正因为「干净」，才能当裁判。

### 过拟合：train 低、val 高

两份 loss 一起看：

```
train↓ + val↓  →  在学（好）
train↓ + val↑  →  在背（过拟合，坏）
```

参数多 + 训练太久 = 过拟合——模型把训练集里的随机噪声也当规律记下来了，但这些「规律」在验证集里不存在，所以验证 loss 反弹。

![训练 loss↓ 验证 loss↑：过拟合的信号 + Early Stopping 的对比效果](/v4/overfitting.png)

### 早停：valLoss 不降就停

最简单的防过拟合：**验证 loss 不再下降就停。**

```typescript
if (valLoss < bestVal) { bestVal = valLoss; patience = 0; }
else { patience++; if (patience >= N) break; }
```

`patience` 是「容忍度」——允许验证 loss 连续不改善的步数。太小可能误停，太大则浪费时间。

## 合在一起：一次完整的训练

```
训练前（做一次）：
  ① 切分     → 训练集 80% + 验证集 20%
  ② 标准化   z = (x − μ) / σ

训练（每圈一个 epoch，五步）：
  ③ 采样     → 随机抽一个 mini-batch
  ④ 前向     z = W_h·x + b_h → ReLU → W_o·h + b_o = ŷ
  ⑤ 损失     L = (ŷ − y)²
  ⑥ 反向     链式法则，算出每个参数的梯度
  ⑦ 更新     lr = cosineLr(epoch)；Adam：W = W − lr·m̂/√(v̂+ε)

评估（每圈之后，旁路）：
  ⑧ 验证     在验证集上跑 ④⑤（不算 ⑥⑦），得 valLoss
  ⑨ 早停     valLoss 连续 N 步没改善 → 停
```

这就是机器学习的全部。不管多复杂的模型——GPT、扩散模型、推荐系统——本质上都在做同一件事：**准备数据 → 训练（预测→损失→梯度→更新）→ 评估**。只是每一步的实现更复杂。
