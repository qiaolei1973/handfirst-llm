# 复习：当我们在谈机器学习时，我们在谈些什么

> 把 v1 到 v4 学过的所有概念，用一条线串起来。不按版本，按"是什么"和"为什么"。

---

## 一个循环

机器学习，说到底，就是让计算机反复做一件事：

```
预测 → 看差多少 → 算往哪改 → 改一点 → 再预测 → …
```

这四步转起来，就构成了**训练**。每一步转一圈叫一个 **epoch**。

所有概念——不管听起来多复杂——都是这四步里某一步的细节。

![训练循环全景：预测→损失→梯度→更新，四步循环，以及标准化、SGD、Early Stopping 等配套概念](/recap/training-loop.svg)

下面我们把这个循环拆开，看看每一步里装着什么。

## 模型：从一条直线到一个网络

**模型**就是"猜答案的公式"。**参数**是公式里可以调的数——训练的目的就是找到一组合适的参数。

### 最基本的运算：Linear

不管模型多复杂，最底层的运算只有一个：

```
y = W·x + b
```

输入 x，乘上**权重（Weight）**，加上**偏置（Bias）**，得到输出。这个操作叫**线性变换（Linear）**，它做三件事：缩放、旋转、平移。

Linear 是砖，所有神经网络都是这块砖垒起来的。

### 为什么需要激活函数

两块 Linear 叠在一起：`W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)`——还是一条直线。

Linear 堆多少层都没用。必须在线性变换之间插入**非线性函数**——**激活函数（Activation Function）**。

```
ReLU(z) = max(0, z)      z>0 时直通，z≤0 时截断
```

ReLU 给了模型"弯折"的能力。没有它，一万层网络也只能画直线。

### 神经元：最小的计算单元

把 Linear 和激活函数捆在一起，就是一个**神经元（Neuron）**：

```
一个神经元 = Linear（加权求和） + 激活函数（决定"放不放、放多少"）
```

名字来自生物神经元的隐喻——树突接收信号，超过阈值才发放脉冲。人工神经元也一样：`ReLU(Wx + b)`，z > 0 才放行。

一个神经元 = 一段折线。换不同的 W 和 b，控制折的位置和方向。

### 隐藏层：把神经元组织起来

N 个神经元并排放置，都接收同一个输入 x，各自算出自己的输出。这一层叫**隐藏层（Hidden Layer）**——"隐藏"的意思是：它的输入和输出都在模型内部，外界看不见。

每个神经元独立做一次 `ReLU(W_i x + b_i)`。N 个神经元 → N 段折线 → 输出一个长度为 N 的向量。

### 输出层：最后一关

隐藏层后面接一层**不带激活函数的 Linear**，把 N 个数加权求和，得到最终预测。

```
输入 x → 隐藏层 (N 个神经元, ReLU) → 输出层 (Linear) → 预测值 yPred
```

这个结构——输入 → 隐藏 → 输出——叫**多层感知机（MLP，Multilayer Perceptron）**。

### Layer：把前向和反向打包

无论隐藏层还是输出层，结构都一样：**Wx + b →（可选激活）→ 输出**。唯一区别是激活函数（ReLU vs 无/直通）。

抽成一个类，暴露两个方法：

```
Layer.forward(x)   → 输出        // 前向：数据流过
Layer.backward(g)  → 传给下游的梯度  // 反向：梯度流回
```

网络 = 几个 Layer 串起来。这是整个 v1–v4 里最重要的抽象。

## 损失：一个数字，衡量"有多差"

模型猜了一个答案。怎么知道猜得好不好？需要一个数字——**损失（Loss）**。

### MAE vs MSE

**MAE**（平均绝对误差）：`L = (1/n) · Σ |yPred − y|`。差多少就是多少，V 形。

**MSE**（均方误差）：`L = (1/n) · Σ (yPred − y)²`。平方之后，差得远的点被罚得更重。曲线是光滑的抛物线。

关键区别不在损失本身，而在**梯度**：

- MAE 求导只剩 `sign(diff)`——差 100 和差 0.01，推动力完全一样
- MSE 求导留着 `2·diff`——差得越远梯度越大，越近自己减速

MSE 是默认选择。

### 两份损失，两个问题

**训练损失（Train Loss）**：在训练数据上算的——"模型对这些数据拟合得怎么样？"

**验证损失（Validation Loss）**：在一份模型没见过的数据上算的——"模型真的学到了规律吗？"

两份 loss 都下降 = 在学。训练 loss 降但验证 loss 升 = 在背（过拟合）。

---

## 梯度：往哪个方向改

知道"有多差"之后，下一步是：**把每个参数往哪个方向调，能让损失变小？**

### 什么是梯度

想象你蒙着眼站在山上，目标是走到山谷最低点。你看不见整座山，但可以用脚感受脚下的地面——**往哪个方向倾斜、倾斜有多陡**。

这个"脚下的坡度"，就是**梯度**。梯度对每个参数分别算：`∂L/∂W`（L 在 W 方向的斜率）、`∂L/∂b`（L 在 b 方向的斜率）。

梯度告诉你两件事：
- **方向**：正梯度 → 参数减小（往下走）；负梯度 → 参数增大
- **陡峭程度**：陡 → 迈大步；缓 → 迈小步

### 链式法则：为什么需要它

单层模型（`y = Wx + b`）的梯度可以直接求导。但多层模型怎么办？

隐藏层的参数（`w_i`, `b_i`）和损失中间隔着 ReLU 和输出层——不能直接求导。答案是**链式法则（Chain Rule）**：

```
∂L/∂w_i = ∂L/∂yPred  ·  ∂yPred/∂h_i  ·  ∂h_i/∂w_i
            ↑                ↑               ↑
        Loss 对预测的导数   输出层对隐藏层的导数  隐藏层对自己的导数
```

梯度从输出端开始，沿网络结构**反方向**一层一层传回去。

### 反向传播：链式法则的实际操作

**反向传播（Backpropagation）**不是一个新数学——它就是链式法则，按层的顺序组织起来。

每一步穿过一层时，要做三个小步骤：

```
backward(上游梯度):
  ① 收：接收上游传来的 ∂L/∂output
  ② 算：用链式法则算出自己参数 (W,b) 的梯度，累加
  ③ 传：算出传给下游的 ∂L/∂input，return 出去
```

"收 → 算 → 传"，每一层都做这三件事。

![前向传播与反向传播：数据从 x 流到 Loss，梯度从 Loss 流回 x](/v3/backprop.svg)

### ReLU 的导数与死神经元

穿过 ReLU 时：`z > 0` → 导数 = 1（直通），`z ≤ 0` → 导数 = 0（截断）。

一旦某个神经元对所有输入都输出 0，它的梯度永远是 0——参数不再更新。这就是**死神经元（Dead Neuron）**。它是 ReLU 的代价。

## 优化器：怎么迈这一步

梯度告诉你"往哪走"。**优化器**决定"怎么迈这一步"——步子多大、要不要带惯性、不同参数是不是用不同的步长。

### 最朴素的走法

```
W = W − lr · ∂L/∂W
```

**学习率（Learning Rate，lr）**控制步长。lr 太小 → 走太慢。lr 太大 → 可能跨过谷底，来回震荡。

这就是**梯度下降（Gradient Descent）**——沿梯度反方向走一小步。

### Mini-batch / SGD：每次只看一小撮

不必每次看全部数据。随机抽一小撮（batch）——只在这些点上算梯度、更新。下一轮再抽不同的一小撮。

**采样**（随机抽一部分数据）和**更新**（`w -= lr*grad`）是两件独立的事。随机采样 + 梯度下降 = **SGD（随机梯度下降）**。

随机性带来了探索能力——每次看到的子集不一样，不会总是走同一条路。代价是 loss 曲线在抖。抖是探索，不是 bug。

### 朴素 SGD 三个问题

1. **没记忆**：每一步只看当前 batch 的梯度，随机抖动直接体现在参数上
2. **一刀切 lr**：所有参数同一个学习率。梯度大的震荡，梯度小的爬不动
3. **只靠 lr**：lr 是唯一旋钮，没有自动调节

优化器的演进就是逐一解决这三个问题。

### Momentum：给梯度加惯性

不直接用当前梯度，而是维护一个"速度"——梯度的**指数移动平均**：

```
v_t = 0.9·v_{t-1} + 0.1·grad    ← 90% 历史 + 10% 当前
W   = W − lr·v_t                 ← 用速度更新，不用原始梯度
```

直觉：一个球从山上滚下来——它不会东一下西一下，它有惯性。方向一致时加速，方向反复横跳时互相抵消。

### RMSProp：每个参数自己的学习率

维护每个参数梯度的"近期波动量"（二阶矩），用它来缩放步长：

```
s_t = 0.999·s_{t-1} + 0.001·grad²    ← 梯度平方的指数移动平均
W   = W − lr·grad / √(s_t + ε)       ← 波动大的参数步子小，波动小的步子大
```

陡的参数自动减速，缓的参数自动加速。一刀切的问题解决了。

### Adam：集大成者

**Adam = Momentum + RMSProp + 偏差修正**：

```
m_t = 0.9·m_{t-1}   + 0.1·grad       ← 一阶矩（Momentum）
v_t = 0.999·v_{t-1} + 0.001·grad²     ← 二阶矩（RMSProp）
m̂_t = m_t / (1 − 0.9^t)               ← 偏差修正（解决早期偏小）
v̂_t = v_t / (1 − 0.999^t)
W   = W − lr·m̂_t / √(v̂_t + ε)
```

**偏差修正**：训练刚开始时 `m_0 = 0`，第一步的 `m_1 = 0.1 × grad`（只有 10%，其余 90% 是 0）。除以 `(1 − 0.9^t)` 把它放大回正确量级。t 增大后修正自动淡出。

Adam 是业界默认首选——拿来就用，几乎不用调。

## 防线：模型真的学会了吗？

### 数据预处理：让输入在公平尺度上竞争

**中心化**：`x' = x − mean(x)`。让数据以 0 为对称轴——梯度推力不再"所有人同号"，自己就平衡了。

**标准化（Z-score）**：`z = (x − μ) / σ`。中心化只平移（mean=0），标准化还缩放（std=1）。当模型有多个参数时，输入尺度一致 → 所有参数的梯度在同一个量级上竞争。单参数时中心化就够了，多参数时必须标准化。

### 训练集 & 验证集

留一部分数据不训练——只用来检验。训练集算梯度、更新参数；验证集不参与训练，只用来看。

```
60 个点 → 48 个训练（80%） + 12 个验证（20%）
```

### 过拟合

训练 loss 一直降，验证 loss 降着降着开始**升**——模型不再学规律，开始**背噪声**。

参数多 + 训练太久 = 过拟合。模型把训练集里的随机噪声也当规律记下来了，但这些"规律"在验证集里不存在。

![训练 loss↓ 验证 loss↑：过拟合的信号 + Early Stopping 的对比效果](/v4/overfitting.png)

### Early Stopping

验证 loss 不再下降就停。设一个 `patience`（容忍连续不改善的步数），给验证 loss 偶尔波动留点余地，但真的开始变差就果断喊停。

## 合在一起：一次完整的训练

一个样本 `(x, y)` 进入训练循环，从头到尾发生了什么：

```
1. 标准化
   x_std = (x - μ) / σ                         ← 数据预处理

2. 前向传播
   z = W_h · x_std + b_h                        ← 隐藏层 Linear
   h = ReLU(z)                                  ← 隐藏层激活
   yPred = W_o · h + b_o                        ← 输出层 Linear

3. 算损失
   L = (yPred − y)²                             ← MSE

4. 反向传播（链式法则）
   ∂L/∂yPred = 2(yPred − y)                    ← Loss 对预测的梯度
   ∂L/∂W_o   = ∂L/∂yPred · h                   ← 输出层 W 的梯度
   ∂L/∂h     = ∂L/∂yPred · W_o                  ← 传给隐藏层的梯度
   ∂L/∂z     = ∂L/∂h · ReLU'(z)                ← 穿过 ReLU
   ∂L/∂W_h   = ∂L/∂z · x_std                    ← 隐藏层 W 的梯度

5. Adam 更新
   m = 0.9·m + 0.1·∂L/∂W                       ← 一阶矩
   v = 0.999·v + 0.001·(∂L/∂W)²                ← 二阶矩
   m̂ = m / (1 − 0.9^t)                          ← 偏差修正
   v̂ = v / (1 − 0.999^t)
   W = W − lr · m̂ / √(v̂ + ε)                    ← 更新参数

6. 验证
   valLoss = 在验证集上跑 1-3（不算 4-5）       ← 只看，不训

7. 如果 valLoss 连续 N 步没改善 → 停           ← Early Stopping
   否则 → 回到第 1 步，处理下一个样本
```

这就是机器学习的全部。不管多复杂的模型——GPT、扩散模型、推荐系统——本质上都在做同一件事：**预测 → 算损失 → 求梯度 → 更新参数**。只是每一步的实现更复杂。
