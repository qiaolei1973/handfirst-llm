# v10：RNN — 让网络有「记忆」（字符级生成）

> 你将学到：序列建模；RNN 的循环结构；隐藏状态；字符级文本生成。

## 梗概

前面的模型输入之间相互独立，但文本里**前面的词决定后面的词**。RNN 用「同一个单元反复用」，靠隐藏状态 `h` 把记忆从一步传到下一步。字符级生成是最直观的 demo——喂一段英文，看它从乱码 → 学会拼词 → 组句。同时在这里埋下 attention 的动机（RNN 的两个痛）。

## 大纲

### 1. 序列问题：输出依赖前面
「前面的字符」决定「下一个字符的概率」。这不是独立样本，是一个时间序列。

### 2. RNN 核心：循环单元 + 隐藏状态
`h_t = tanh(W·x_t + U·h_{t-1} + b)`。同一个参数反复用，`h` 是「到目前为止的摘要」。

### 3. 时间展开：反向传播穿过时间
把循环展开成一条链，用回 BPTT（backprop through time）算梯度。

### 4. 字符级生成 demo
喂几 MB 英文文本，看模型逐步学会：字母频率 → 拼词 → 空格断词 → 简单语法。

### 5. RNN 的两个痛（为 v12 埋伏笔）
- **顺序处理**：必须一个接一个算，不能并行（慢）
- **梯度消失**：隔远了信息衰减，记不住长程依赖（忘事）

### 6. 代码
- `RNNCell`（一个时间步）
- 循环展开 + softmax 输出下一个字符

## 关键可视化

- 生成的文本随训练逐步「变像英语」
- loss 曲线

## 与上一版的关系

v9 解决了「词→向量」，v10 解决「序列→怎么处理」。RNN 是 transformer 之前的序列标准解，也是理解「attention 为什么是革命」的必要动机。
