# v11：翻译 — 编码器-解码器 + 注意力（seq2seq）

> 你将学到：seq2seq（变长进、变长出）；注意力（对齐）；英→中翻译。

## 梗概

翻译是**变长输入 → 变长输出**，不是一一对应，还要解决「哪个词对应哪个词」（对齐）。编码器读完整句，解码器逐词生成；**注意力**在生成每个词时，给输入句子里的每个词打分（softmax）、加权求和，得到「当前该看的上下文」。这一版 softmax 第一次用在了「动态选择信息」上。

## 大纲

### 1. 翻译的难点
变长（英 5 词 → 中 3 词）、词序不同、对齐（哪个对哪个）。

### 2. seq2seq：编码器 → 解码器
编码器把整句编码成一个向量/序列；解码器逐词生成目标语言。教师强制（teacher forcing）技巧。

### 3. 注意力：软对齐
`attention(Q, K, V) = softmax(QKᵀ/√d)·V` 的雏形——对每个输入词算一个「相关性分数」，softmax 归一化成权重，加权求和。

### 4. 代码
- Encoder（读英文）
- Decoder（生成中文）
- Attention 层

### 5. 观察：attention 权重可视化
看模型生成每个中文词时「盯着」哪个英文词——对齐矩阵热图。

### 6. 局限
小词表、短句、CPU 友好规模（几千词表、seq ≤ 32）。这是教学 demo，不是可用翻译器。

## 关键可视化

- attention 对齐矩阵（英文词 × 中文词的热图）
- 翻译结果随训练进步

## 与上一版的关系

v10 的 RNN 处理单个序列；v11 用两个 RNN（编码器/解码器）+ attention 处理「序列到序列」。attention 的引入是通往 transformer 的桥。
