# v6：图片就是函数 — f(x,y) → RGB

> 你将学到：把一张图看成「像素坐标 → 颜色」的函数；用 MLP 拟合图片；通过「图片显影」观察收敛。

## 梗概

v5 拟合的是二维曲面（输入 `(x₁,x₂)` → 输出一个标量）。这一版把**输出从一个数变成三个数（R,G,B）**，输入换成像素坐标 `(x,y)`——模型就成了一张「会自己显影的图片」。这是「函数逼近」主线的视觉收官，几乎零新概念。

## 大纲

### 1. 一张图 = 一个函数
图片本质是「像素坐标 → 颜色」的映射。RGB 三个通道 = 三个并排的标量函数。灰度图 = 一个函数，彩色图 = 三个函数。

### 2. 和 v5 的关系：输出 1 维 → 3 维
架构不变，只改两处：输入 `(x,y)` 代替 `(x₁,x₂)`，输出层 `1 → 3`。其余（Linear、ReLU、Adam、反向传播）原样复用。

### 3. Demo：显影过程
随机初始化的网络输出一张噪点图，训练时图片从模糊 → 轮廓 → 清晰。收敛不再需要看 loss 数字，**直接看图片变清楚**。

### 4. 代码改动
- `surfaceData` → 图片数据（读一张图 / 生成一张图）
- 输出层 `new Linear(2, 3)`（或 `numNeurons, 3`）
- 损失仍是 MSE（逐像素差）

### 5. 局限：这还不是「真」图像处理
模型拿到的是**坐标** `(x,y)`，不是**原始像素**。真实图像任务（分类、检测）输入是像素本身，且要处理局部结构——这是 v7/v8 的引子。

## 关键可视化

- 显影 GIF / 多帧对比：同一张图在不同 epoch 的样子
- loss 曲线（可选，弱化——这一版主角是图片本身）

## 与上一版的关系

v5 的「函数逼近」直觉直接延伸，只换输出维度，让学习者先「看见」逼近的威力，再进入真正的新概念（v7 分类）。
