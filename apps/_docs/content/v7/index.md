# v7：分类 — softmax 与交叉熵（MNIST）

> 你将学到：从回归到分类；softmax；one-hot；交叉熵损失；MNIST 手写数字。

## 梗概

前 6 版全是**回归**（输出一个连续值）。这一版转向**分类**（输出「是哪个类别」）。核心新概念是 **softmax**——把网络输出的 logits 变成「和为 1 的概率分布」。它是 transformer attention 的心脏，这里在 MNIST 这个静态、干净的任务上单独拿下它。

## 大纲

### 1. 问题变了：要的是「0-9 哪个数字」
手写数字识别。输出不再是连续值，而是「属于 0、1、…、9 各的概率」。

### 2. 回归做分类会失败
为什么不能直接输出一个数、再用阈值切？类别之间没有数值顺序、阈值难定、误差无意义。

### 3. softmax：logits → 概率分布
`softmax(z)_i = e^zᵢ / Σ e^zⱼ`。输出每个元素在 (0,1) 且和为 1。可以读作「置信度」。

### 4. one-hot 标签 + 交叉熵损失
标签 `3` → `[0,0,0,1,0,...]`。交叉熵 `-Σ y·log(ŷ)` 度量「预测分布和真实分布差多远」，替代 MSE（MSE 对分类梯度太弱）。

### 5. MNIST 数据：28×28 拍平成 784
60000 张灰度手写数字。二维图拍平成 784 维向量输入（丢失空间信息——为 v8 埋伏笔）。

### 6. 代码
- 输出层 `new Linear(128, 10)`
- 前向末尾加 softmax
- 损失换成交叉熵

### 7. 观察
loss / accuracy 曲线；看错分类的样例（模型「搞混」了哪两个数字）。

## 关键可视化

- accuracy 曲线（分类任务的新指标）
- 误分类样例展示

## 与上一版的关系

v6 还是回归；v7 引入第一个真正的新概念 **softmax + 交叉熵**。这是翻译（预测下一个词 = 分类）和 transformer（attention 里用 softmax）的公共前置。
