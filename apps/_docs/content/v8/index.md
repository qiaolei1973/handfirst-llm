# v8：卷积 — 让网络「看见」空间结构（CNN）

> 你将学到：卷积核、感受野、池化；为什么「拍平」会丢掉空间信息。

## 梗概

v7 把 28×28 拍平成 784 维，丢掉了「相邻像素有空间关系」这个关键信息。CNN 用一个小窗口（卷积核）在图上滑动，专门捕捉局部特征——这是图像任务的标准架构，也是「网络结构本身编码了空间先验」的第一次体现。

## 大纲

### 1. MLP 的问题：拍平丢掉空间
784 维向量里，像素 (1,1) 和 (1,2) 相邻这个信息没了；MLP 每个输入神经元都连所有输出，参数多且不懂局部性。

### 2. 卷积核：滑动的小窗口
一个 3×3 的核在图上滑动，每次做「窗口内加权求和」，检测局部模式（边缘、角、纹理）。

### 3. 参数共享
同一个核扫全图——「检测横边的核」在任何位置都适用。参数从几十万降到几千。

### 4. 池化：降采样
MaxPool 在局部取最大，缩小尺寸、保留主要特征、带来一点平移不变性。

### 5. 代码
- `Conv2d`（卷积 + 反向）
- `MaxPool2d`
- 结构：`Conv → ReLU → Pool → Conv → ReLU → Pool → Linear → softmax`

### 6. 观察
CNN 在 MNIST 上比 MLP 更快收敛、更高准确率，且参数更少。

## 关键可视化

- 卷积核学习到的模式（第一层核通常学成边缘检测器）
- 特征图（中间层「看到了什么」）

## 与上一版的关系

v7 的 MNIST 分类不变，只是把「拍平 MLP」换成「卷积」，让学习者体会「架构先验」的价值。这是图像分支的收尾，之后转向文本。
