# v9：嵌入 — 从词到向量（tokenization + embedding）

> 你将学到：分词（token 化）；词嵌入；从 one-hot 到稠密向量。

## 梗概

进入文本（NLP）的第一步：**怎么把词变成数字**。one-hot 维度爆炸、且任意两个词距离都一样（无相似性）。嵌入把每个词映射成一个**可学习的稠密向量**，语义相近的词向量也相近——这是所有现代 LLM 的地基。

## 大纲

### 1. 文本怎么变数字
分词（token 化）→ 建词表 → 每个词一个 id。词/子词/字符级分词的取舍。

### 2. one-hot 的两个问题
维度 = 词表大小（几万维）；任意两词的内积都是 0，无法表达「猫 ≈ 狗」。

### 3. 嵌入：每个词一个低维稠密向量
`Embedding(token) = W[token]`，一个查表操作。维度从几万降到几十/几百，且向量之间的几何关系编码语义相似性。

### 4. 嵌入是学出来的
Embedding 矩阵的每一行是**可学习参数**，随任务一起训练。同一任务学出的嵌入才有意义。

### 5. 代码
- `Embedding` 层（本质是「查表 + 可学习权重矩阵」）
- 把 token id 序列 → 向量序列

### 6. 观察
训练后把词向量降维可视化，语义相近的词聚在一起。

## 关键可视化

- 词向量 2D 投影（相近词聚成簇）
- 类比（`king - man + woman ≈ queen`，可选）

## 与上一版的关系

从「像素 → 数字」切换到「词 → 数字」，是图像分支到文本分支的转折。嵌入是后面 RNN/transformer 的输入层，是文本路径的第一个地基。
