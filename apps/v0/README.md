# v0 · 认识机器学习

## 什么是机器学习？

一句话：**让计算机从数据里自己找出规律。**

传统编程是你告诉计算机规则——"如果温度 > 30，就开空调"。机器学习反过来：你给计算机一堆（输入, 输出）的例子，让它自己琢磨出规则。

```
传统编程:  规则 + 输入 → 输出     （人写规则）
机器学习:  输入 + 输出 → 规则     （机器学规则）
```

比如这里的例子：给你 12 个 (x, y) 散点，你知道背后是 `y = 2x + 10` 这条直线。但计算机不知道。它要从零开始**学**出 W 和 bias，让 W·x + bias 算出来的 y 尽可能接近真实的 y。

这就是机器学习里最**简单**也最**核心**的问题——线性回归。

## 怎么学？三个问题

计算机学一条直线，要回答三个问题：

| 问题 | 对应概念 |
|------|----------|
| 1. 当前直线好还是差？ | **损失函数（Loss）** |
| 2. 往哪个方向调能变好？ | **梯度（Gradient）** |
| 3. 每次调多大？ | **学习率（Learning Rate）** |

### 1. 损失函数：你的直线有多差？

模型预测 `yPred = W·x + bias`，真值是 y。看一眼差多少：

```
MAE（平均绝对误差）:  L = (1/n) · Σ |yPred - y|
```

`|差值|` 的意思是只看距离不看方向——预测高了低了都算"差"。

### 2. 梯度：往哪调？

我们现在有了 L(W, bias)，想知道"W 变大一点，L 会变大还是变小"。这就是**偏导数**：

```
∂L/∂W    = (1/n) · Σ sign(yPred - y) · x
∂L/∂bias = (1/n) · Σ sign(yPred - y)
```

`sign` 只看正负：预测大了 sign=1（W 要减），预测小了 sign=-1（W 要加），方向很直观。

### 3. 学习率：步子多大

算出梯度后，沿着梯度的**反方向**走一小步：

```
新W    = 旧W    - learnRate · ∂L/∂W
新bias = 旧bias - learnRate · ∂L/∂bias
```

学习率 0.1 意思是"梯度的 10% 那么大步"。太大则震荡，太小则蜗牛。

## 看一眼代码

打开 `train_simple.ts`，从头到尾 60 行，你会发现上面的数学就是全部逻辑：

```
linear(x, W, bias)          ← 模型预测
diff = yPred - target       ← 误差
sign = ±1                   ← MAE 的梯度方向
gradW += sign·x             ← 累加 W 梯度
gradBias += sign            ← 累加 bias 梯度
W -= learnRate * gradW      ← 更新参数
```

## 不足

回顾一下你看到的：W 一步跳到真值附近，但 bias 半天才挪一点点。

[图片] 插入 L(W) 和 L(bias) 两张图并排对比

目前这套方案至少有三个问题：

1. **损失函数只看方向。** MAE 的 sign 不看误差大小——差 100 和差 0.1，推动力都是 1。快接近目标了也不知道减速，反而一步跨过去。
2. **参数收敛不一致。** W 的梯度乘了 x，bias 的梯度只到 ±1。数据范围越大差距越悬殊，一个冲过头，一个走不动。
3. **数据不平衡。** x 全部 ≥0，所有点的 sign 在 W 上贡献同号——每个 epoch 都把 W 往同一个方向推，加剧了震荡。
4. **每次算全量数据。** 每次都用全部数据计算梯度，每一步都走同一条确定性路径，缺少随机性——容易被鞍点卡住走不动，也没有机会"碰运气"跳出更优的解。
