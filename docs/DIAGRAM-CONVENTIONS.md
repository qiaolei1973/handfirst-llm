# 图表规范

本文档沉淀 handfirst-llm 项目中的图表绘制经验，后续新增图表时可直接参考。

---

## 工具选择

| 工具 | 适合 | 不适合 |
|---|---|---|
| **matplotlib** (Python) | 数据图：散点图、loss 曲线、拟合效果对比 | 架构图、流程图 |
| **Excalidraw** | 架构图、计算图、流程图、渐进讲解图 | 需要自动布局的大量节点图（30+） |
| **D2** (已弃用) | — | — |

**决策原则**：如果图的布局需要"教学意图"（哪里放哪里是有意义的），用 Excalidraw。如果图是纯数据驱动的，用 matplotlib。

---

## Excalidraw 图类型与规范

### 1. 计算图（Computational Graph）

用于解释算法过程，灵感来自 Chris Olah 的 [Calculus on Computational Graphs](https://colah.github.io/posts/2015-08-Backprop/)。

**要素：**
- **节点**：全部用圆形（`ellipse`），代表一个值或操作的结果
- **边**：灰色箭头，**在边上直接标注局部偏导数**（如 `∂z/∂x = W`）
- **前向流**：从左到右，灰色箭头 →
- **梯度流**：从右到左，红色箭头 ←，**粗细递减**暗示梯度衰减
- **参数节点**（W, b）：比主值节点小一号，从上方/下方汇入

**颜色：**
- 输入 x：灰 `#e2e8f0 / #64748b`
- 中间值 z：蓝 `#dbeafe / #3b82f6`
- 激活 h：黄 `#fef9c3 / #f59e0b`
- 预测 ŷ：绿 `#d1fae5 / #10b981`
- 损失 L：红 `#fee2e2 / #ef4444`
- 参数 W, b：紫 `#f5f0ff / #8b5cf6`
- 梯度箭头：红 `#ef4444`
- 偏导标注：深灰 `#64748b`

**渐进披露（Progressive Disclosure）：**
- 一个 master 文件包含所有节点和边
- 每个元素的 `groupIds` 标注它属于哪些步骤（`["step-1", "step-5"]`）
- `generate-steps.py` 生成 N 个步骤变体：当前 step 全亮（opacity 100），其余 dim（opacity 15）
- 元素标 `"all"` → 始终可见（如标题、分隔线）
- 示例：`backprop-steps.excalidraw` + `generate-steps.py`

```
Master 文件结构：
  node-x:  groupIds: ["step-1", "step-5"]
  node-z:  groupIds: ["step-1", "step-4", "step-5"]
  edge-x-z: groupIds: ["step-1", "step-5"]
  grad-L:  groupIds: ["step-2"]
  title:   groupIds: ["all"]

生成 5 张图：
  step-1:  node-x, node-z, edge-x-z 亮，其余 dim
  step-2:  grad-L 亮，其余 dim
  ...
```

### 2. 结构图（Architecture Diagram）

用于展示概念之间的层级/组成关系。

**要素：**
- **容器**：大虚线矩形表示一个语义范围（"隐藏层"、"完整网络"）
- **内部节点**：圆或方，保持同语义同形状
- **递进箭头**：虚线连接三个模块，表示"逐步构建"的关系
- **颜色层级**：每个模块容器有自己独特的颜色，内部节点通用色

**颜色约定：**
- ① 神经元模块：紫色容器 `#f5f0ff / #8b5cf6`
- ② 隐藏层模块：黄色容器 `#fffdf5 / #f59e0b`
- ③ 完整网络：蓝色外框 `#f0f9ff / #3b82f6`
- **神经元（Linear+ReLU）**：统一紫色 `#f5f0ff / #8b5cf6` — 任何地方出现的神经元都用这个色
- **输出层（Linear only）**：绿色 `#ecfdf5 / #10b981`
- **输入/输出值（x, ŷ）**：灰色圆 `#e2e8f0 / #64748b`
- 递进箭头：淡紫 `#a78bfa`，虚线，opacity 40%

**布局：** 横向并排（左→中→右），每个模块内部纵向排列。

### 3. 流程图（Flow Diagram）

用于展示循环、步骤序列。

**要素：**
- **步骤节点**：圆角矩形，每个步骤一种颜色
- **箭头**：节点之间，箭头颜色和源节点一致
- **循环返回**：多点箭头从最后一步绕回第一步，箭头颜色和步骤一致

## 渐进披露模式（母版 + 脚本）

当需要用"同一张图 + 逐步高亮"来解释算法时，使用此模式。

**文件结构：**
```
scripts/v3/
  backprop-steps.excalidraw    ← 母版（受 git 管理）
  generate-steps.py            ← 生成脚本（受 git 管理）
  backprop-step-1.excalidraw   ← 生成产物（gitignore）
  backprop-step-2.excalidraw   ← 生成产物（gitignore）
  ...
```

**构建集成：** `generate-all.ts` 在收集源文件前先调用 `generate-steps.py`，产物也通过 excalirender 渲染。

**关键规则：**
1. 永远只编辑母版文件，不要手动编辑步骤变体
2. 母版文件中每个元素用 `groupIds` 声明它属于哪些步骤
3. 全局元素（标题、分隔线）标 `"all"`
4. 脚本用 `copy.deepcopy` 避免意外修改原始数据

## 颜色体系总览

| 语义 | 边框 | 填充 | 用途 |
|---|---|---|---|
| 输入/输出 | `#64748b` | `#e2e8f0` | x, ŷ |
| 线性/中间值 | `#3b82f6` | `#dbeafe` | z |
| 激活函数 | `#f59e0b` | `#fef9c3` | h, ReLU |
| 预测/输出层 | `#10b981` | `#d1fae5` | ŷ, 输出层 |
| 损失/错误 | `#ef4444` | `#fee2e2` | L |
| **神经元** | `#8b5cf6` | `#f5f0ff` | 任何 Linear+ReLU 组合 |
| 参数 | `#8b5cf6` | `#f5f0ff` | W, b（小圆） |
| 梯度箭头 | `#ef4444` | — | 反向传播红色箭头 |
| 普通边 | `#94a3b8` | — | 前向灰色箭头 |

**原则：** 同语义同颜色。如果一个概念在不同模块里出现，用同样的配色让读者一眼识别。

## 布局原则

1. **计算图**：水平（左→右 = 输入→输出），梯度反向叠加。水平比垂直省空间，且符合自然阅读方向。
2. **结构图**：水平三栏并排，模块间虚线递进箭头连接
3. **流程图**：水平四节点 + 曲线返回（用多点箭头）
4. 节点间距：水平 60-110px，垂直 40-60px
5. 容器内边距：标题 15px from top，节点 20-30px from edges

## 常见问题

**Q: roughjs 多点箭头转角断开？**
excalirender v0.1.6+ 已修复 — `multiPath()` 将多点路径自动拆为独立 2-点段渲染。

**Q: 步骤图 dim 百分比？**
15% — 刚好可辨识但不分散注意力。不要低于 10%（完全看不见），不要高于 25%（和活跃元素混淆）。
