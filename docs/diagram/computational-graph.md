# 计算图（Computational Graph）

## 表达什么

数据如何一步一步被变换，导数如何一步一步回传。

## 识别特征

- 节点是**值**（圆），边是**操作**（箭头 + 偏导数标注）
- 正反向流**共用同一组边**——灰色箭头 → 是前向数据流，红色箭头 ← 是梯度回传
- 简洁、数学化，一张图通常不超过 10 个节点

## 什么时候用

需要解释"这个算法的数据怎么流动、梯度怎么回传"时。典型场景：

- 反向传播的链式法则
- 任何涉及导数/梯度的逐步推导
- 前向 + 反向的对称性展示

## 什么时候不用

- 概念层级关系（用结构图）
- 步骤序列 + 循环（用流程图）
- 节点太多（>15 个）且自动布局更合适——但教学中通常不需要

## 设计要点

- **一张图只讲一个数据流路径**——不要把所有层堆进去，一段计算就够了
- **边上标偏导数**比在旁边写公式直观——读者同时看到"从哪到哪"和"怎么变"
- **颜色区分方向**——前向值用不同颜色（蓝、黄、绿…），梯度箭头统一红色
- **粗细暗示强度**——梯度箭头从输出端到输入端逐渐变细，暗示信息衰减
- **配合渐进披露**——一图多态，逐步高亮当前步骤

## 与结构图的区别

结构图问"它由什么组成"，计算图问"数据经过了哪些变换"。
