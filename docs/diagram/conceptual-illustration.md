# 概念插图（Conceptual Illustration）

## 表达什么

解释一个抽象概念（矩阵、向量、张量、概率分布……）**在物理世界中对应什么**——不是怎么算，而是"它是什么"。

## 识别特征

- 不是节点 + 边的图结构——本质上是**带标注的图解**
- 核心元素：色块网格、行列标注、连线映射、实体照片（可选）
- 信息密度比传统图高——一张图通常叠加 3-4 层注释
- 视觉层次分明：用颜色深浅、字号大小、边框粗细区分主次

## 什么时候用

需要对读者说"这个数学对象代表的是一组真实事物"时。典型场景：

- 数据矩阵 = 一张表，行是样本，列是特征
- 权重矩阵 = 神经元的连接模式，横向看是一个神经元，纵向看是一个特征
- 矩阵乘法 = 每个输出是所有输入的加权和
- 向量 = 空间中的一个点或一个方向
- 概率分布 = 对不同结果的信心分配

## 什么时候不用

- 数据如何逐步变换（用计算图）
- 概念如何层层构建（用结构图）
- 步骤序列（用流程图）
- 纯数学公式推导——概念插图配公式，不替代公式

## 设计要点

- **找到物理锚点**——先问"读者生活中见过什么东西跟它像"，从那个锚点出发
- **不是精确对应**——矩阵不是真的等于 Excel 表格，但"表格"这个类比帮读者建立第一直觉
- **标注层级**——最靠近元素的是"这是什么"，稍远的是"它和旁边的关系"，最远的是"它整体在做什么"
- **用熟悉的命名代替符号**——标"卧室数"不标 x₂，至少在第一次出现时
- **颜色编码要跨图一致**——同一概念在不同插图里用同一颜色

## 常见模式

### 表格模式（矩阵 → 数据表）

矩阵画成格子，行标注"样本1、样本2…"，列标注"面积、卧室数…"。强调"矩阵 = 组织好的数据"。

### 连接模式（权重矩阵 → 连接网）

矩阵两维各标注对象（输入特征 / 输出神经元），格子颜色表示权重大小。强调"矩阵 = 跨两组对象的关系"。

### 变换模式（矩阵 → 线性变换）

输入向量 → 网格变形 → 输出向量。强调"矩阵 = 对空间的操作"。

## 与 Excalidraw 的关系

概念插图通常在 Excalidraw 里手绘——它不依赖自动布局，位置和间距本身就是信息。可以混合使用矩形、圆、线、文字，但核心逻辑是"标注式的"而非"图论式的"。

## 参考

- 3Blue1Brown, *Essence of Linear Algebra* — 线性变换的几何直觉（变换模式）
- Kenji Hiranabe, *The Art of Linear Algebra* — 矩阵运算的彩色网格图解（表格模式 + 连接模式）
- PyTorch, *Inside the Matrix* — 矩阵乘法的 3D 可视化（连接模式）
