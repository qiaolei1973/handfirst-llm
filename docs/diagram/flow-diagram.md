# 流程图（Flow Diagram）

## 表达什么

一个循环或流程的步骤序列。读者看完全图应该能说出"哪一步接哪一步，最后怎么回到开头"。

## 识别特征

- **步骤节点**（圆角矩形），每个步骤一种颜色
- **箭头**串联步骤，箭头颜色跟源节点走
- **返回箭头**闭合循环——这是流程图的视觉锚点
- 循环外的辅助概念用**小节点 + 虚线**引入

## 什么时候用

需要展示"一件事反复做，每圈经历哪些阶段"。典型场景：

- 训练循环（Forward → Loss → Gradient → Update → 回到 Forward）
- 数据 pipeline（采集 → 清洗 → 训练 → 评估）
- 任何有闭环的算法步骤序列

## 什么时候不用

- 数据值的逐步变换（用计算图）
- 概念层级和组成（用结构图）
- 没有闭环的线性步骤——用简单的 → → → 箭头链就行，不需要独立成图

## 设计要点

- **返回箭头让读者看清"这是个圈"**——这是流程图最重要的信息
- **步骤间箭头颜色跟源节点**——帮助追踪每一步的输出去向
- **辅助概念用小节点挂在边上**——不要塞进主循环节点里
- 步骤数控制在 4-6 个——太多说明抽象层级不对，应该合并或拆成两级

## 与计算图的区别

计算图的箭头带偏导数标注，同一边双向使用。流程图的箭头只表达顺序，不承载数学信息。
