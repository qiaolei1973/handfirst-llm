# 图设计

## 选择图类型

先回答三个问题：

1. **这张图要回答什么问题？**（不是"我要画什么"，是"读者看完要理解什么"）
2. **核心关系是什么？**（数据流过步骤？概念层层构建？循环反复？抽象概念到物理含义？）
3. **需要分步展示吗？**（如果算法有多个阶段，用渐进披露）

| 核心关系 | 图类型 | 例 |
|---|---|---|
| 数据逐步变换 + 导数回传 | [计算图](./computational-graph.md) | 反向传播 |
| 概念从简单到复杂的递进 | [结构图](./structure-diagram.md) | 神经元 → 隐藏层 → 网络 |
| 步骤序列 + 闭环 | [流程图](./flow-diagram.md) | 训练循环 |
| 抽象概念 → 物理含义 | [概念插图](./conceptual-illustration.md) | 矩阵 = 数据表 |

## 四种类型速查

| | 计算图 | 结构图 | 流程图 | 概念插图 |
|---|---|---|---|---|
| 问什么 | 数据怎么变 | 由什么组成 | 步骤怎么串 | 它是什么 |
| 节点 | 圆（值） | 方/圆（组件） | 圆角矩形（步骤） | —（非图结构） |
| 边 | 箭头 + 偏导数 | 虚线递进或实线组成 | 箭头 + 返回闭环 | — |
| 关键视觉 | 同一边双向 | 容器 + 跨阶段一致 | 返回箭头 | 色块网格 + 标注层级 |

## 设计流程

1. **写提纲**——用文字把要表达的核心关系写清楚
2. **选类型**——按上面的对照表
3. **列概念清单**——图中会出现哪些独立概念？每个配一种颜色
4. **画骨架**——先画节点和边，不加文字；检查布局是否清晰
5. **加标签**——能放边上的不放在旁边，能放节点里的不单独写
6. **对照检查**——同一个概念在前面的图里用过吗？颜色一致吗？
